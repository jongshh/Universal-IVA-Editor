# Universal-IVA-Editor
Add / Replace IVA and Props in-game (and more)

Closed Beta (26/11/05)
*Testing exclusively on the JSIndustries Discord server.*

This build is intended for closed beta testing only.
Do not redistribute, reupload, or share this build outside the server without permission.

Testing Status
- Tested with Jongsh's modpack.
- Not fully tested in a stock KSP environment (with required dependencies installed).

# Installation

Required Dependencies
- KSP 1.12.x
- HarmonyKSP

Soft Dependencies
- ModuleManager 4.2.3

Supported Mods
- RasterPropMonitor (RPM)
- ASET Props / ASET Avionics (Props)
- FreeIVA
- FAR / Chatterer / HullcamVDS-related ASET props

Requires Further Testing
- Reviva (framework integration option added)

Not Yet Tested
- Probe Control Room Recontrolled

Important;
This is an experimental beta release.
Compatibility issues, unexpected behavior, and bugs may occur.

If you encounter any issues, please report them through GitHub Issues and attach your KSP.log.

# Preset Sharing

Sharing presets is easy. Simply share the .cfg file located in the PluginData folder.

However, both players must have the same IVA mods and props installed for the preset to work correctly.

# Preset Compatibility

I will try to maintain compatibility with existing IVA data in future versions.

However, please keep in mind that this mod is still in beta. Your IVA data may not be preserved across updates, and compatibility is not guaranteed.
What This Mod Doesn't Do
This mod does not modify IVA meshes or support editing colors, shaders, materials, or other similar properties.
I currently have no plans to add these features, as the main goal is to keep the mod lightweight and minimize conflicts with other mods.
